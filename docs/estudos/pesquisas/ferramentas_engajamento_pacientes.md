# Ferramentas para nutricionistas engajarem e atenderem melhor os pacientes

Pesquisa focada em Mayara — atendimento online, nicho principal Diabetes Gestacional, secundário emagrecimento comportamental feminino. Preços de referência em BRL, abril 2026. Confirmar valores nos sites antes de contratar.

---

## 1. Prontuário eletrônico e gestão do consultório

| Ferramenta | O que faz | Preço/mês | Prós | Contras |
|---|---|---|---|---|
| **Nutrium** | Prontuário + plano alimentar + app do paciente + chat | R$ 180–290 | App do paciente é o melhor do mercado BR/PT, chat integrado, registro fotográfico de refeições | Mais caro, curva de aprendizado |
| **Dietbox** | Prontuário + cálculo nutricional + app do paciente | R$ 90–170 | Bom custo-benefício, interface limpa, tem app para paciente | App do paciente mais básico que Nutrium |
| **Dietpro** | Prontuário clínico + cálculo (software desktop tradicional) | R$ 100–150 | Robusto para cálculo, referência antiga do mercado | Sem app moderno para paciente, engajamento fraco |
| **Doctoralia / BoaConsulta** | Agenda + perfil público + lembretes automáticos de consulta | R$ 150–300 | Capta pacientes novos, reduz faltas | Não é prontuário completo, é captação |

**Recomendação para Mayara:** Nutrium se quiser engajamento máximo via app, Dietbox se quiser economizar e ter app razoável.

## Prioridades práticas para Mayara agora

Com base no sprint atual (Essência em tráfego, foco em conversão):

1. **Curto prazo (30 dias):** ativar Dietbox ou Nutrium trial + criar grupo Telegram "Essência DG" para alunas + começar a usar LibreView como diferencial.
2. **Médio prazo (60–90 dias):** automação ManyChat Instagram→WhatsApp + GPT custom "Essência Companion" + NPS trimestral via Tally.
3. **Longo prazo (6 meses):** migrar grupo para Circle se Essência escalar + WhatsApp API + infoproduto separado na Hotmart.

O salto de engajamento mais barato e imediato: **grupo Telegram segmentado + LibreView compartilhado + registro fotográfico no Nutrium**. Nada disso passa de R$ 300/mês e muda a experiência da paciente.
