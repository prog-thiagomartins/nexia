# Insights — Site Principal

## Decisões estratégicas

### Posicionamento da hub
- **Hub é a porta de entrada da marca.** Não é landing de venda — é onde quem chega frio (Google, cartão, link bio) entende quem é a Mayara e escolhe o caminho.
- **Conversão ≠ landing comercial.** Sucesso aqui é "clicou num caminho", não "fechou contrato". Cada caminho tem sua própria página/canal de fechamento.

### SEO duplo: Google + IA search
- **Schema Person + MedicalBusiness + FAQPage** é a base. Google + ChatGPT/Perplexity entendem entidade.
- **`sameAs` apontando pro Instagram** boosta reconhecimento de entidade (skill schema-markup).
- **NAP completo no footer** alimenta Google My Business (skill site-architecture).
- **Anchor text descritivo** com palavra-chave (não "saiba mais", mas "Programa Essência — emagrecimento comportamental").

### Blog: NÃO agora
- 1 post/mês não move SEO. Precisa de 2-4/mês consistentes por 6+ meses.
- Mayara já posta no Instagram — dobrar trabalho.
- **Alternativa melhor (futuro):** páginas evergreen densas (`/diabetes-gestacional`, `/nutricao-comportamental`), 2000+ palavras, com FAQ. Cada uma vira landing SEO permanente.

### URL structure futuro
- `mayarafarias.com.br/` → hub (essa)
- `mayarafarias.com.br/diabetes-gestacional` → pillar evergreen (quando criar)
- `mayarafarias.com.br/nutricao-comportamental` → pillar evergreen (quando criar)
- `essencia.mayarafarias.com.br` → landing produto (subdomínio mantido — é landing de venda)

### Por que NÃO criar diretório/seção sem página real
- Skill site-architecture: chips de "Especialidades" só viram link quando a página existir. Senão, são chips visuais estáticos.

### NÃO inventar
- Formação acadêmica, pós-graduação, anos de experiência, especializações específicas.
- Aprendizado: já errei em iteração anterior ("pós-graduada em Nutrição Comportamental"). Sempre verificar nos arquivos antes de afirmar credencial.

### Sobre a "Consulta Avulsa"
- **NÃO desvalorizar.** É 90 min, plano alimentar personalizado, suporte WhatsApp 30 dias, R$350.
- NÃO escrever como "uma sessão única para uma dúvida" — minimiza o serviço.
- Escrever como atendimento completo individual sem compromisso de longo prazo.
