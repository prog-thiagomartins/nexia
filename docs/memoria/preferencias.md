# Preferências da Mayara

## Pipeline de reels
- Claude gera roteiro com cenário especificado → Mayara grava → CapCut edita e publica
- Deixar 5s de padding no início e fim — ela apara no CapCut, não tentar acertar via IA
- Texto no bottom third do frame (y > 1480px) — nunca cobrir o rosto
- Sem box de fundo nos textos — usar outline + shadow

## Cenários disponíveis para gravação
- Quintal com piscina, áreas verdes, próxima à praia, consultório, cozinha

## Formato de resultados
- Roteiros com cenário especificado — ela decide onde gravar, não a IA
- Prefere receber o vídeo pronto para ajuste final, não 100% automatizado

## O que não funciona
- Tentar acertar corte exato via ffmpeg — custo/benefício ruim, deixar para o CapCut
- Fontes genéricas (Arial) em reels — usar Bebas Neue + Montserrat
- Texto no meio do frame — cobre o rosto
